# Aurelle — website starter

A responsive static storefront concept for an Egypt-focused jewelry and accessories brand.

## Preview
Open `index.html` in a web browser. Internet is needed to load the optional Google Fonts; the site still works without them.

## Before launch
1. Replace the sample products and prices in `script.js` with your real inventory.
2. Add your WhatsApp number to `WHATSAPP_NUMBER` in `script.js`, using country code 20 and digits only (example format `2010XXXXXXXX`, not a real number).
3. Add your customer-service email to `CONTACT_EMAIL`.
4. Replace the abstract product artwork with your own product photographs if available.
5. Add shipping, returns, privacy, and terms information that matches your business.
6. Test on mobile and desktop.

## Free publishing with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new **public** repository, for example `aurelle-store`.
3. Upload `index.html`, `styles.css`, and `script.js` to the repository root (not the ZIP file).
4. Open the repository's **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section, usually `https://YOUR-USERNAME.github.io/aurelle-store/`.

GitHub Pages is suitable for a free static catalogue/demo. This site does not include a secure payment checkout, inventory management, or a shipping integration. The WhatsApp button can send an order enquiry after you add your real number; you must confirm orders and payments yourself. Do not collect card details in this static site.
